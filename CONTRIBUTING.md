# Contributing to QLooper RC1

Please open an issue with a reproducible problem, expected/actual behaviour,
build version, macOS, audio device, sample rate and buffer size. Attach a short
recording or minimal session only if you have the right to share it; remove
private recordings, plugin presets and credentials first.

RC1 is focused on stability. Code pull requests are not being accepted until
contributor licensing terms are agreed. This preserves a clear boundary for a
future separately licensed plugin; it does not change licences already granted.
See LICENSING.md. Please do not sign an upstream SAP CLA for this project.
