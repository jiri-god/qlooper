QLooper RC2 — Nektar Pacer A1 (JGOD)

File: QLooper-Pacer-A1-RC2-2026-11-10.syx
Contains only the saved A1 JGOD preset, including LED colours.
A2 Pads and all other presets are excluded. Global Config is not included.

1. Connect Pacer; open https://studiocode.dev/pacer-editor/ in a Web MIDI browser.
2. Select PACER MIDI1 input/output. Read Pacer and export your own backup first.
3. Import/Export → Load file → choose this .syx.
4. Select only A1 JGOD, then Send to Pacer. This replaces slot A1 only.
5. Recall another preset, then A1. No factory reset is needed.
6. Enable and route MIDI in QLooper; use Assign as needed for your session.

See MAPPING.txt. Actions depend on QLooper settings; Pacer sends press/release.
Read from hardware on 2026-11-10. A1 messages extracted unchanged from the verified
A1/A2 export. No messages synthesized, no device write or re-import performed.
