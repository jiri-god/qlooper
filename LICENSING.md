## Future paid VST/AU

Charging for software is permitted by GPL/AGPL. A **closed-source** future plugin
is a separate licensing task, not a right conferred by this repository's licence.
We intend to reuse independently authored QLooper code where the project has
sufficient rights, under separate commercial terms if appropriate. This cannot
relicense Element, JUCE or anyone else's contributions.

Before a proprietary build: audit provenance per component, separate/replace
GPL-only host integration, obtain a suitable commercial JUCE licence, and clear
all other dependencies and contributions. A new wrapper alone does not remove
copyleft obligations. Existing open-source releases remain available under the
licences already granted.

## Contributions

**4lt s.r.o.** Contributor terms are still being prepared; this statement does
not transfer copyright or change any upstream licence.

For RC1, please submit bug reports and reproduction steps. Code contributions
are not being accepted until contributor terms have been agreed. We will not
silently incorporate outside code into a future closed-source edition. Authors
retain their rights; any additional licensing permission must be explicit.
No SAP or upstream CLA applies merely by reporting an issue here.
